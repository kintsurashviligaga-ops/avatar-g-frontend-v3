## 2. Delivered

### Chat — like Google's
- **Google Search grounding on every turn and every door.** Signed-out turns were never grounded unless `CHAT_GUEST_SEARCH=1`,
  and an ungrounded turn's prompt tells the model to say its information may be out of date — the "I cannot provide
  real-time information" answers. Now on by default (`CHAT_GUEST_SEARCH=0` turns it off; the guest daily caps still bound
  the cost). The Strict Coder persona searches too.
- **One Agent G everywhere.** `/api/chat` (the service widgets) and the channels (WhatsApp, Telegram, phone) used the legacy
  13.7 KB prompt or an OpenAI engine production never calls; they now use the same platform prompt and Gemini Flash chain
  as the main chat (`lib/ai/google/reply.ts`).
- **Every service its own session.** A chat, then Video, then the Photographer no longer pile into one thread: picking a
  tool opens its own session (the one it had in this visit, or a fresh one), History lists them separately, and opening one
  from History returns to its tool. `tests/service-sessions.spec.ts`.

### Agent G directs before anything is spent
- Image / Video / Music (previous round) **and now Avatar and plain chat**: talk is answered in words, a thin prompt gets
  2–3 questions, a real prompt gets a card with the price and renders only on Create. A "draw me…" in the chat used to start
  a paid render on the sentence; "აქ ხარ?" in Avatar used to become a paid talking-head video. `tests/agent-g-gate.spec.ts` (14).
- With a Higgsfield model picked, Agent G points to the panel's Generate (that model's own price) instead of rendering
  the Google model in its place.

### Models
- **Model Selector** in the Image and Video panels (and Studio β): Google is the default (Nano Banana Auto / V2 / Pro; Veo 3.1
  Lite / Fast / Standard); Higgsfield models are opt-in rows — Soul 2 and eight more image models, Kling 3 (std / pro / turbo /
  4K, text and image to video), Seedance 2.5 (t2v / i2v / reference), motion transfer (Kling 3 / 2.6, Genjutsu). Every
  Higgsfield entry cites its docs page; unverified ones run only when named in `HF_ENABLED_MODELS`.
- A Higgsfield pick runs from the panel through the Studio β saga with the server's estimate on the button.
- `/api/nanobanana/image` validates the picked model before any lock or charge.

### WhatsApp (Agent G, two-way)
- Linking by a one-time code sent **from** the number (Settings → WhatsApp → "Get code" → "Open WhatsApp"). ⚠️ A browser
  can no longer attach a number to an account (anyone could have claimed someone else's).
- Replies through the Cloud API within seconds (the webhook answers after its 200); the worker tick now answers GET (Vercel
  Cron calls GET — every scheduled run had been a 405, so the queue was never drained).
- Talk is answered; "make me…" gets a studio link with the request typed in; help / stop / alerts on / unlink.
- Alerts when a video, image, music or Deep Research run finishes (with the bell and Web Push — `lib/notifications/dispatch.ts`).

### Web Push · Connectors hub
- Web Push opt-in card, subscribe / test routes, service-worker notifications that only ever open our own site.
- Connectors · Plugins · Skills hub (sidebar row): documents, notifications, WhatsApp, Telegram status; per-user tool switches
  (menu only); an honest list of what Agent G can do here.

### Fixes found on the way
- Telegram: replies are awaited (a fire-and-forget send can be frozen with the function), a per-chat reply brake, and a real
  model timeout (3 s cut almost every answer into the canned fallback).
- Photo + music video: the clip now ends with its track (`-shortest` alone overshot — a 2 s tone came out 27.5 s).
