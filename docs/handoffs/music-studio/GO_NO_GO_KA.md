## რა არის მზად (BUILT, ტესტებით)
- სრული ნაკადი: იდეა → გეგმა → ფასი (quote) → აშკარა დადასტურება → კრედიტის დაკავება → Lyria → ხარისხის შემოწმება (ffmpeg) → საბოლოო აუდიო → ბიბლიოთეკა. ღილაკზე დაწერილი ფასი ზუსტად ის თანხაა, რაც ჩამოიჭრება.
- გამძლე სამუშაო (lease): ტელეფონის ჩაკეტვა, დაკარგული კავშირი ან მოკლული ფუნქცია სამუშაოს არ კარგავს. ერთი quote-ის განმეორება ორჯერ არ იხდევინებს. მარცხი, გაუქმება ან ხარისხის ვერგავლა თანხას **ზუსტად ერთხელ** აბრუნებს. Lyria-ზე შესაძლოა უკვე გაგზავნილი მოთხოვნა ხელახლა არასდროს იგზავნება.
- რედაქტირება (ffmpeg, უფასო, ორიგინალი არ იცვლება): მოჭრა, ხმა/დადუმება, fade in/out, გაერთიანება (crossfade-ით), mp3/wav/m4a.
- Agent G-ის ერთ ფანჯარაში: გეგმის ბარათი, ფასი, დადასტურება, რეალური ეტაპი (**ყალბი პროცენტების გარეშე**), გაუქმება, პლეერი, ჩამოტვირთვა, ბრძანებებით რედაქტირება (ka/en/ru), ახალი ვარიანტი. ყველაფერი ფლაგის მიღმაა და ნაგულისხმევად გამორთულია.
- პროვაიდერის საზღვარი: მუსიკას მხოლოდ Google Lyria ქმნის. Udio, ElevenLabs Music, Replicate (MusicGen, Demucs, MiniMax, RVC) და Pollinations ნებისმიერ თანხის ჩამოჭრამდე იბლოკება. ბიუჯეტის შემოწმება ახლა „დახურულად" ვარდება: გაუმართავი შემოწმება ხარჯვის უფლებას აღარ იძლევა.
