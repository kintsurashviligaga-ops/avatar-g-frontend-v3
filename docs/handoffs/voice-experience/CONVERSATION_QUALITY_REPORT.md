# Conversation quality — evidence and listening protocol
Automated evidence proves control flow, locale UI, fixed style-command routing and reply-policy construction. It does not prove natural Georgian speech, pronunciation, humor timing, accent, emotional appropriateness or truthfulness of a live model.
Native streaming, local barge-in, server interruption, resumption, microphone retry and output priming are reused. No second speech engine runs alongside native audio. Dictation remains editable text; protected OmniStudio still has legacy auto-read assignments until the supplied patch is integrated.
Read-aloud faithfully retains complete/selected text; it is explicit, sequential, cancellable, pausable and speed-controlled. Reader tests include Stop during pending synthesis and refusal to overlap native calls. Actual spoken fidelity and word boundaries across chunk transitions need listening review.
