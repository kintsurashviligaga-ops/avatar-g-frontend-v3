# Voice benchmark — reference capabilities, not a measured ranking
No comparative live sessions were run. Public descriptions inform acceptance criteria, not claims of parity or superiority.
| Dimension | Reference / lesson | Agent G evidence |
|---|---|---|
| Full-duplex speech | ChatGPT Voice conversational interruption | Existing transport tests |
| Barge-in | ChatGPT noise/network caveats require real-device testing | Simulated PASS; hardware BLOCKED |
| Turn timing | Sesame TurnBench evaluates turn-taking behavior | Eagerness wire tests; no measured latency |
| Contextual prosody | Sesame research ties delivery to conversation | Prompt guidance; listening BLOCKED |
| Persistent character | Sesame highlights consistent personality | Eight validated presets |
| Expressive intent | Hume Octave describes context-sensitive delivery | Internal style representation only |
| Voice identity | Separate voice and delivery selection | Two existing voices, independent style |
| Silence controls | ElevenLabs conversation-flow controls | Model-gated VAD settings |
| Expressive tags | ElevenLabs expressive mode is provider-specific | Tags deliberately not transferred to Google |
| Short versus complete speech | Product acceptance criterion | Brief policy + explicit faithful reader |
| Tool authority | Product-specific safety requirement | Spoken paid dispatch blocked before executor |
| Language and mobile UX | Must test the actual locale/device | KA/EN/RU mobile browser PASS; live Georgian BLOCKED |
Sources: [ChatGPT Voice guidance](https://help.openai.com/en/articles/20001274/), [Voice FAQ](https://help.openai.com/en/articles/8400625-voice-mode-faq), [Sesame voice research](https://www.sesame.com/journal/crossing-the-uncanny-valley-of-voice), [TurnBench](https://www.sesame.com/journal/turnbench), [Hume Octave](https://www.hume.ai/octave), [ElevenLabs conversation flow](https://elevenlabs.io/docs/eleven-agents/customization/conversation-flow), [expressive mode](https://elevenlabs.io/docs/eleven-agents/customization/voice/expressive-mode). No competitor SDK or paid service was introduced.
