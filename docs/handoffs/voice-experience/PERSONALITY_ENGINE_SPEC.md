# Personality Engine v1 / Voice Experience v2
Implemented in lib/voice/experience/settings.ts, commands.ts, preferences.ts and components/voice/experience.
Eight presets: Friendly, Professional, Critical, Sarcastic, Humorous, Calm, Creative, Coach. Voice identity (Aoede/Charon) is independent. Settings: pace, answer length, humor, opt-in sarcasm, expression, turn eagerness, language and tone. Fixed enum validation strips unknown fields and future schemas; no user-authored system prompt.
Preferences are per-account, device-local, versioned and deletable. They are not cloud-synchronized and are not an authorization mechanism. Account switching resets to the appropriate preferences without briefly exposing another account's selection.
Feature switch: NEXT_PUBLIC_VOICE_EXPERIENCE_V2=1, off by default. ChatChrome exposes localized settings and wraps the existing native call with context. Mid-call style updates wait until listening and preserve the conversation; voice and VAD changes apply next call. No fabricated claim that Google changes voice in an existing session.
Brief replies request 1–3 short sentences. Style does not grant tools, change prices or weaken authentication. Humor/sarcasm are prohibited in billing, security, safety, distress and serious complaints by the system instruction. This is model guidance, not a deterministic semantic classifier. Listening verification remains required.
Regression evidence: experience.test.ts, VoiceSettingsPanel.test.tsx, useGeminiLiveSession.test.tsx. Session test observes no style message while speaking, one update at listening, unchanged mint count, and new voice on next call.
