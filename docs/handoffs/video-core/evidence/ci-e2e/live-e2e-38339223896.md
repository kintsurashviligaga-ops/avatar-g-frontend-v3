## The six failures — root cause (test, not product)

The tests attached a fresh 6 s file and said „Trim it from 1 to 4 seconds" / „Make it 2x speed" / „Slow motion please".
On an attached file the product hands trim and speed words to the chat model's remix (`lib/agent/chatTurn` `editStep`:
on an attached video only frame-shape, effects and layers are Agent G's own edit; Media Studio v2 behaviour). This job
has no model credential by design, so the chat answered with an error (server log: `Gemini chat failed: auth`) and no
edit quote was ever sent. Agent G's own edit lane takes the same words on the video **it delivered** (AC-11, „edit of a
delivered video", `source: 'previous'`, no model involved; pinned in `lib/agent/chatTurn.test.ts`).
