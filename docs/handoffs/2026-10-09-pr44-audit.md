**The three claims in 8ee92f76, checked against main:**

- **"Images render on Google again": not true in main.** `/api/nanobanana/image` is the route behind the image tool, the photographer and the interior designer. In main it runs the NanoBanana reseller and nothing else (`app/api/nanobanana/image/route.ts:298-345`). R7 removed Grok and FLUX, so it has no fallback: if the reseller's balance is empty, every render fails with 502 and a refund.
  - The chat image path is Imagen, which is opt-in and off, and then FLUX and NanoBanana (`lib/chat/ServiceManager.ts:396-428`).
  - Only the storyboard frames are drawn by Gemini.
  - `lib/ai/geminiImage.ts` in main has no `imageSize` and no mapping from endpoint to model.
- **"A dead Redis costs 0.1 s instead of 4.4 s": still true in main.** Seven modules build `new Redis({ url, token })` with the library's default of 5 retries (`node_modules/@upstash/redis/nodejs.js`: `retries ?? 5`). They are:
  - `app/api/health/route.ts:117`
  - `lib/chat/filmStatusStore.ts:208`
  - `lib/orchestrator/idempotency.ts:30`
  - `lib/orchestrator/rate-limit.ts:37`
  - `lib/orchestrator/sse-hub.ts:35`
  - `lib/platform/cache.ts:17`
  - `lib/platform/redis.ts:37`, which feeds the studio semaphore

  `lib/api/rate-limit.ts` calls Redis with plain `fetch` and no retry, so it is not affected. I did not check whether the Production Upstash host is still NXDOMAIN.
- **"Voice can run every service": not in main.** `LIVE_STUDIO_TOOLS` in `lib/voice/liveTools.ts:66` lists video, image, music, avatar, presentation and model3d. `LIVE_GEN_TOOLS` in `OmniStudio.tsx:6902/7024/7148` lists 4 tools. Photoshoot, interior, product, swap and remix can be opened by voice (`open_tool`) but cannot be prepared or started.

6. **#25 Telegram Agent G STT → Gemini.** Flag-gated, clean.
