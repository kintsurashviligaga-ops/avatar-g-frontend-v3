# Pinned brand fonts

The root layout uses these local variable WOFF2 faces through `next/font/local`. Inter, Montserrat and Noto Sans Georgian, the existing CSS variables, normal styles, display swap and weight ranges remain. Building no longer fetches mutable Google Fonts CSS or assumes every returned font URL ends in an extension. The observed Linux CI failure was `google/loader.js` reading `[1]` from a null extension match, before any Video Core tests.

Sources are the official [Google Fonts repository](https://github.com/google/fonts), pinned to the commit and original SHA-256s in `sources.json`. Each included OFL file retains its original copyright/license. FontTools4.60.2 pins unrequested axes to their normal defaults (Inter optical size14, Georgian width100), retains the weight axis and all glyphs, then serializes WOFF2 using Node's Brotli font mode. Conversion round-trips verify every cmap entry, glyph order, horizontal metric and key vertical metrics. Output SHA-256s and byte sizes are recorded. No glyph subsetting or replacement family is used.

These are about524KB total. The normal `next/font/local` loader computes fallback metrics and emits self-hosted assets; it does not require a font-download mock or a patched dependency. See [Next.js local-font documentation](https://nextjs.org/docs/app/getting-started/fonts#local-fonts). `lib/brand/localFonts.test.ts` uses the same binary parser as the build and verifies hashes, Latin/Cyrillic/Georgian coverage and variable weight support. The offline build and browser evidence remain separate from provider/media certification.
